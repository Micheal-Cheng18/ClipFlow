# 手动验收

编译不能替代 GUI 验证。请记录 macOS 版本、构建版本与以下项目结果：

- 复制两段测试文本，搜索、重复复制去重、点击粘贴。
- 固定、取消固定、删除；清空只移除未固定项；重启确认持久化。
- 浏览器/预览复制图片及截图进入历史，显示缩略图，粘贴到备忘录。
- 图片固定后重启仍保留，图片删除及清空行为正确。
- 顶部拖动有效，搜索与所有按钮保持可点击。
- 多屏四角唤起，检查窗口边界；Esc、外部点击、失焦关闭。
- 深浅色、减少动态效果、空列表和搜索无结果布局。
- 暂停后新复制内容不入历史；恢复后后续复制正常。
- 未授予辅助功能时可手动粘贴；授权后自动恢复原应用并粘贴。
